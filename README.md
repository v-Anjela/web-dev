# Event Booking Platform

## Project Description

The Event Booking Platform is a website designed to help users discover
and book different events such as music concerts, conferences, birthday
parties, business seminars, and end-year parties.

The project demonstrates the use of HTML5 and CSS in developing a
structured and styled website.

## Course Information

- Course Code: CSC2130
- Course Name: Introduction to Web Development
- Project: Event Booking Platform
- Laboratory: Week 2 and Week 3

## Project Objectives

1. Create a multi-page website using HTML5.
2. Use semantic HTML elements.
3. Create navigation links between pages.
4. Display images using the img element.
5. Create structured HTML tables.
6. Embed audio and video.
7. Embed Google Maps using an iframe.
8. Apply CSS styling to web pages.

## Project Files

- index.html: Home page
- about.html: About the platform
- blog.html: Event articles and blog posts
- contact.html: Contact information and Google Maps
- data.html: Event information table
- gallery.html: Event images, table, and video
- style.css: Website styling

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Ensure all image and media files are in their respective folders.
4. Open index.html using Firefox or another web browser.
5. Navigate through the website using the navigation menu.
